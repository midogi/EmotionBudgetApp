# EmotionBudgetApp 최종 시연 흐름

이 문서는 3분 이내 제출 영상과 최종 보고서의 앱 설명 순서를 맞추기 위한 체크리스트다.

## 영상 흐름

1. 앱 실행 후 `기록` 화면 소개
   - 앱 목적: 수입/지출과 소비 당시 감정을 함께 기록하는 감정 가계부.
   - 빈 화면이면 `샘플 데이터 불러오기`를 눌러 시연 데이터를 준비한다.

2. 기본 가계부 기능 시연
   - `지출` 기록을 하나 추가한다.
   - 금액, 날짜, 카테고리, 감정, 메모가 함께 저장되는 점을 보여준다.
   - 기존 기록의 `수정`, `삭제` 버튼을 짧게 보여준다.

3. 기록 찾기 기능 시연
   - 검색어에 `카페`, `스트레스`, 또는 금액을 입력한다.
   - `검색하기` 버튼을 눌러 검색 결과 개수와 결과 없음 문구가 바뀌는 것을 보여준다.
   - 기간, 유형, 카테고리, 감정 필터를 함께 선택할 수 있음을 보여준다.

4. 통계 화면 시연
   - 하단 `통계` 탭으로 이동한다.
   - 월 이동 버튼, 일일/달력/주별/월별/요약 탭을 보여준다.
   - 이번 달 수입, 지출, 잔액과 날짜별 기록 묶음을 보여준다.

5. 감정 분석 화면 시연
   - 하단 `감정` 탭으로 이동한다.
   - `소비 패턴 분석` 카드에서 감정별 지출 금액 그래프와 소비 빈도 그래프를 보여준다.
   - `감정 소비 진단` 카드에서 위험도, 주요 감정, 추천 행동을 설명한다.
   - 스트레스 소비 증가/감소 문구와 감정별 상세 분석을 보여준다.

6. 마무리
   - 차별점: 단순 가계부가 아니라 감정 기반 소비 패턴을 분석하고 행동 제안까지 제공한다.
   - 보완 계획: 장기 사용을 위해 Room DB 저장 기능을 추가할 수 있다.

## 보고서에 넣기 좋은 핵심 문장

- EmotionBudgetApp은 사용자의 수입/지출 기록에 감정 태그를 함께 저장해 소비 상황과 감정의 관계를 분석하는 앱이다.
- 기록 화면에서는 금액, 유형, 날짜, 카테고리, 감정, 메모를 입력하고 검색/필터로 원하는 기록을 빠르게 찾을 수 있다.
- 통계 화면에서는 월별 이동, 일별 기록 묶음, 주별/월별 합계, 요약 지표를 제공해 기본 가계부 기능을 완성했다.
- 감정 분석 화면에서는 감정별 지출 금액과 소비 빈도를 그래프로 시각화하고, 스트레스 소비 증가 여부와 감정 소비 진단 결과를 제공한다.
- 이 앱의 차별점은 지출 금액만 보여주는 것이 아니라 소비 당시의 감정을 기반으로 소비 패턴과 개선 행동을 제안한다는 점이다.

## 촬영 전 체크리스트

- Android Studio에서 최신 `codex/basic-ledger-features` 브랜치를 Pull 한다.
- `Sync Project with Gradle Files` 후 앱을 실행한다.
- 앱 실행 직후 데이터가 없으면 `샘플 데이터 불러오기`를 눌러 그래프와 진단 카드가 잘 보이게 한다.
- 영상은 `기록 -> 통계 -> 감정` 순서로 찍고, 각 화면에서 20~40초 정도만 보여준다.
- 유튜브 업로드 후 로그아웃 상태에서도 링크 재생이 되는지 확인한다.
