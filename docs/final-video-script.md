# EmotionBudgetApp 최종 제출 영상 대본

이 문서는 최근 수정된 기능을 반영한 3분 이내 제출 영상용 대본이다.

목표 시간은 2분 45초 안팎이다. 말이 조금 느리면 3분 가까이 걸리므로, 화면 전환은 빠르게 하고 핵심 기능 위주로 보여준다.

## 촬영 전 준비

- Android Studio에서 `codex/basic-ledger-features` 브랜치를 최신 상태로 Pull 한다.
- `Sync Project with Gradle Files`를 실행한 뒤 앱을 실행한다.
- 첫 화면에서 기록이 비어 있으면 아래쪽의 `샘플 데이터 불러오기` 버튼을 누른다.
- 샘플 데이터에는 2026년 4월, 5월, 6월, 7월 기록이 들어 있다.
- 2026년 6월 데이터는 주차별로 나뉘어 있으므로 통계 화면에서 주별/일별 예시를 보여주기 좋다.
- 녹화는 Android Studio 전체보다 에뮬레이터 화면이 크게 보이도록 찍는다.

## 영상 진행 순서

| 시간 | 화면 | 보여줄 장면 |
|---|---|---|
| 0:00~0:15 | 기록 화면 상단 | 앱 이름과 목적 소개 |
| 0:15~0:35 | 기록 화면 | 샘플 데이터 불러오기 또는 기록 입력 영역 소개 |
| 0:35~1:05 | 기록 찾기 | 검색어, 유형, 카테고리, 감정, 금액 범위 필터로 결과 카드 표시 |
| 1:05~1:45 | 통계 화면 | 2026년 6월 일일/주별 통계와 월 이동 |
| 1:45~2:30 | 감정 화면 | 감정별 금액/빈도 그래프, 감정 소비 진단, 스트레스 변화 |
| 2:30~2:50 | 감정 화면 또는 통계 화면 | 차별점과 개선 방향 정리 |

## 실제 대본

### 0:00~0:15 앱 소개

안녕하세요. 제가 만든 앱은 EmotionBudgetApp, 감정 가계부입니다.

일반 가계부처럼 수입과 지출을 기록하는 것뿐만 아니라, 소비할 때의 감정까지 함께 저장해서 감정별 소비 패턴을 분석하는 앱입니다.

### 0:15~0:35 기록 화면 소개

먼저 기록 화면입니다.  
이 화면에서는 수입과 지출을 선택하고, 금액, 날짜, 카테고리, 감정, 메모를 입력할 수 있습니다.

시연을 위해 샘플 데이터를 불러오면 2026년 4월부터 7월까지의 수입과 지출 기록이 자동으로 들어갑니다.

등록된 기록은 아래 목록에서 확인할 수 있고, 수정과 삭제도 가능합니다.

### 0:35~1:05 기록 찾기와 금액 필터

다음은 기록 찾기 기능입니다.  
검색어에는 메모, 날짜, 유형, 감정, 금액을 입력할 수 있고, 상세 필터에서는 기간, 수입/지출 유형, 카테고리, 감정까지 선택할 수 있습니다.

이번에 금액 범위 필터도 추가해서 최소 금액과 최대 금액으로 원하는 기록을 더 정확하게 찾을 수 있습니다.

예를 들어 유형을 지출로, 카테고리를 식비로 선택하고 검색하면 아래에 검색 결과 카드가 바로 표시됩니다.

샘플 데이터에는 2026년 6월 5일 식비 55,555원 기록이 있어서, 검색 결과가 실제 지출 카드 형태로 보이는 것을 확인할 수 있습니다.

### 1:05~1:45 통계 화면

이제 하단의 통계 탭으로 이동하겠습니다.

통계 화면에서는 월별로 수입, 지출, 잔액을 확인할 수 있고, 이전 달과 다음 달로 이동할 수 있습니다.

샘플 데이터에는 2026년 4월, 5월, 6월, 7월 기록이 들어 있어서 월 이동 기능을 바로 확인할 수 있습니다.

특히 6월 데이터는 주차별로 나뉘어 있어서 일일, 달력, 주별, 월별, 요약 탭을 누르면 같은 기록이 여러 관점으로 정리됩니다.

이렇게 기록이 많아져도 날짜별, 주별, 월별로 소비 흐름을 확인할 수 있습니다.

### 1:45~2:30 감정 분석 화면

다음은 이 앱의 핵심 차별점인 감정 분석 화면입니다.  
감정별 지출 금액과 소비 빈도를 그래프로 보여줘서 어떤 감정일 때 소비가 많이 발생했는지 한눈에 볼 수 있습니다.

예를 들어 스트레스 감정에서 카페나 쇼핑 지출이 반복되면, 감정별 상세 분석에 총액과 횟수, 평균 금액이 표시됩니다.

또 감정 소비 진단 카드에서는 스트레스 소비 횟수, 지난달 대비 변화, 지출 비중을 기준으로 위험도를 계산합니다.

단순히 기록만 보여주는 가계부가 아니라, 감정적인 소비를 발견하고 줄일 수 있도록 추천 행동까지 제공하는 점이 이 앱의 핵심입니다.

### 2:30~2:50 마무리

정리하면 EmotionBudgetApp은 기본 가계부 기능, 기록 검색, 금액 범위 필터, 월별/주별 통계, 감정별 분석을 모두 포함한 앱입니다.

기존 가계부와 다른 점은 지출 금액뿐 아니라 소비 당시의 감정을 분석해서 스트레스 소비 같은 패턴을 진단한다는 점입니다.  

향후에는 Room DB를 연결해서 앱을 종료해도 기록이 저장되도록 발전시킬 수 있습니다.

이상으로 프로젝트 시연을 마치겠습니다.

## 촬영 중 실제 조작 순서

1. 앱 실행 후 `기록` 탭 상단을 보여준다.
2. 기록이 0개면 아래로 내려 `샘플 데이터 불러오기`를 누른다.
3. `기록 찾기`에서 상세 필터를 열고 `유형: 지출`, `카테고리: 식비`를 선택한다.
4. 필요하면 `최소 금액: 50000`을 입력하고 `검색하기`를 누른다.
5. 아래 `검색 결과`에 `지출 · 식비`, `-55,555원` 카드가 나오는 장면을 보여준다.
6. 하단 `통계` 탭으로 이동해 2026년 6월 기록을 보여준다.
7. `주별` 또는 `요약` 탭을 눌러 6월 데이터가 주차별로 나뉘어 있음을 보여준다.
8. 월 이동 버튼으로 5월이나 7월 기록도 짧게 보여준다.
9. 하단 `감정` 탭으로 이동해 감정별 그래프와 감정 소비 진단 카드를 보여준다.
10. 마지막 멘트에서 “감정 기반 소비 분석이 차별점”이라고 강조한다.

## 시간이 부족할 때 줄일 부분

- 새 기록을 직접 입력하는 장면은 생략해도 된다.
- 통계 화면에서는 모든 탭을 다 누르지 말고 `주별`과 `요약`만 보여줘도 된다.
- 감정 화면은 반드시 보여준다. 창의성 점수에 가장 직접적으로 연결되는 화면이다.
- 마지막 Room DB 개선 방향은 한 문장만 말해도 충분하다.
