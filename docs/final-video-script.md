# EmotionBudgetApp 3분 이내 제출 영상 대본

이 문서는 기말 프로젝트 제출 영상 촬영용 진행 순서와 읽을 대본이다. 전체 영상은 2분 40초에서 2분 55초 정도를 목표로 촬영하면 안정적이다.

## 촬영 전 체크리스트

- Android Studio에서 `codex/basic-ledger-features` 브랜치가 최신인지 확인한다.
- 상단 `Sync Project with Gradle Files`를 한 번 실행한다.
- 앱을 실행한 뒤 데이터가 비어 있으면 `샘플 데이터 불러오기`를 눌러 통계와 감정 분석 화면이 바로 보이게 한다.
- 화면은 에뮬레이터 앱 화면 위주로 찍고, 코드 화면은 길게 보여주지 않는다.
- 영상 업로드 후 유튜브 로그아웃 상태에서도 URL이 재생되는지 확인한다.

## 영상 진행 순서

| 시간 | 화면 | 보여줄 내용 |
|---|---|---|
| 0:00~0:15 | 앱 첫 화면 또는 Android Studio 실행 화면 | 앱 이름과 목적 소개 |
| 0:15~0:45 | 기록 화면 | 수입/지출 기록, 날짜, 카테고리, 감정, 메모 입력 기능 |
| 0:45~1:10 | 기록 찾기 영역 | 검색어와 필터로 기록을 찾는 기능 |
| 1:10~1:45 | 통계 화면 | 월 이동, 일일/달력/주별/월별/요약 탭, 수입/지출/잔액 |
| 1:45~2:35 | 감정 화면 | 감정별 그래프, 감정 소비 진단, 스트레스 소비 변화 |
| 2:35~2:55 | 감정 화면 또는 마무리 화면 | 차별점과 보완 계획 정리 |

## 3분 대본

### 0:00~0:15 앱 소개

안녕하세요. 제가 만든 앱은 EmotionBudgetApp입니다.  
이 앱은 일반 가계부처럼 수입과 지출을 기록하는 것에서 끝나지 않고, 소비할 때의 감정까지 함께 저장해서 감정별 소비 패턴을 분석하는 앱입니다.

### 0:15~0:45 기록 기능 소개

먼저 기록 화면입니다.  
사용자는 금액을 입력하고, 수입인지 지출인지 선택할 수 있습니다.  
그리고 날짜, 카테고리, 감정, 메모를 함께 입력할 수 있습니다.  
예를 들어 카페 지출을 기록하면서 감정을 스트레스로 선택하면, 나중에 스트레스 소비 분석에 이 기록이 반영됩니다.  
등록된 기록은 목록에서 바로 확인할 수 있고, 수정과 삭제도 가능합니다.

### 0:45~1:10 기록 찾기 기능 소개

다음은 기록 찾기 기능입니다.  
검색어에 카페나 스트레스처럼 원하는 단어를 입력하면 해당 기록만 찾을 수 있습니다.  
검색 대상은 카테고리, 감정, 메모, 금액까지 포함됩니다.  
또 기간, 유형, 카테고리, 감정 필터를 함께 적용할 수 있어서 기록이 많아져도 원하는 소비 내역을 빠르게 찾을 수 있습니다.  
검색 결과가 없으면 없다는 문구가 보여서 사용자가 현재 상태를 바로 알 수 있습니다.

### 1:10~1:45 통계 화면 소개

이제 통계 화면입니다.  
상단에서 월을 이전 달이나 다음 달로 이동할 수 있고, 이번 달의 총수입, 총지출, 잔액을 확인할 수 있습니다.  
아래에는 일일, 달력, 주별, 월별, 요약 탭이 있어서 같은 기록을 여러 방식으로 볼 수 있습니다.  
일일 화면에서는 날짜별로 기록이 묶이고, 요약 화면에서는 카테고리별 지출이나 가장 큰 지출 같은 핵심 정보를 확인할 수 있습니다.

### 1:45~2:35 감정 분석 화면 소개

다음은 이 앱의 핵심 차별점인 감정 분석 화면입니다.  
먼저 소비 패턴 분석 카드에서 감정별 지출 금액과 소비 빈도를 그래프로 볼 수 있습니다.  
예를 들어 스트레스 감정에서 얼마를 썼는지, 몇 번 소비했는지를 한눈에 확인할 수 있습니다.  
그리고 감정 소비 진단 카드에서는 스트레스 소비 횟수, 지난달 대비 증가 여부, 지출 비중을 바탕으로 위험도를 계산합니다.  
단순히 통계만 보여주는 것이 아니라, 추천 행동까지 제공해서 사용자가 감정적인 소비를 줄일 수 있도록 돕습니다.  
아래 상세 분석에서는 감정별 총액, 평균 지출, 횟수 변화도 확인할 수 있습니다.

### 2:35~2:55 마무리

정리하면 EmotionBudgetApp은 기본 가계부 기능, 검색과 필터, 월별 통계, 감정별 분석을 모두 포함한 앱입니다.  
기존 가계부와 다른 점은 지출 금액뿐 아니라 소비 당시의 감정을 분석해서 스트레스 소비 같은 패턴을 진단한다는 점입니다.  
추가로 발전시킨다면 Room DB를 연결해서 앱을 종료해도 기록이 유지되도록 만들 수 있습니다.  
이상으로 프로젝트 시연을 마치겠습니다.

## 촬영 팁

- 시간이 부족하면 직접 새 기록을 입력하는 장면은 생략하고 샘플 데이터가 들어간 상태로 설명한다.
- 통계 탭은 전부 오래 누르지 말고 `일일`, `요약` 정도만 빠르게 보여준다.
- 감정 화면은 반드시 보여준다. 이 앱의 차별점이 가장 잘 드러나는 화면이다.
- 말이 길어지면 “추천 행동” 설명은 한 문장만 읽고 넘어간다.
- 영상 마지막에는 “Room DB는 향후 개선 방향”이라고 말하면, 현재 DB가 없어도 보완 계획이 명확해 보인다.
